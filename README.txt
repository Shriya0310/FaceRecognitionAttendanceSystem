Face Recognition Attendance System

Description:
A standalone face recognition system developed using ArcFace, InsightFace, SQLite and CustomTkinter.

Features:
- Face Enrollment
- Face Recognition
- Confidence Score Display
- SQLite Database Storage
- View Registered Users
- Delete Users
- Professional Dashboard UI
- Executable Application (.exe)

Technology Stack:
- Python
- InsightFace (ArcFace)
- OpenCV
- SQLite
- CustomTkinter
- ONNX Runtime

Modules:
1. Enrollment Module
2. Recognition Module
3. User Management Module
4. Dashboard Module

Developed as Internship Project.
